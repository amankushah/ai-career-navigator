AI Career Navigator - Working Prototype

How to run:
1. Keep index.html, style.css and app.js in the same folder.
2. Open index.html in any modern browser.
3. Enter a profile, select skills and click "Analyze My Career Path".

Prototype behavior:
- Uses transparent skill-overlap scoring to recommend roles.
- Shows skill gaps and a simple roadmap.
- This is an internship demonstration prototype, not a production employment prediction system.
